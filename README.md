# Actividad 3 - Calculadora con pruebas unitarias

Proyecto académico desarrollado en Python para implementar una calculadora básica y validar su funcionamiento mediante pruebas unitarias con `unittest`.

## Objetivo

El objetivo de esta actividad es reforzar la práctica de programación y pruebas de software mediante una aplicación sencilla capaz de realizar las cuatro operaciones matemáticas básicas:
- Suma
- Resta
- Multiplicación
- División

Además, se incluyen pruebas unitarias para comprobar que cada función devuelve el resultado esperado ante distintos casos de entrada.

## Tecnologías utilizadas

- Python
- unittest
- Git
- GitHub
